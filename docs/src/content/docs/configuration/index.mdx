`ghtui` has extensive configuration options.

- Modify the default config which is usually under `$HOME/.config/ghtui/config.yml`.
- Use the [`--config`][01] flag to specify a different configuration file.
- Create a `.ghtui.yml` file in a repo for project specific configuration.

<details>
  <summary>Give me more details!</summary>
  Using the following logic:
1. If `$GHTUI_CONFIG` is a non-empty string, `ghtui` will use this file for
   its configuration.
2. If `$GHTUI_CONFIG` isn't set and you're in a git repository, it will look for `.ghtui.yml` or `.ghtui.yaml`
   in the repository root.
3. If neither of the above applies, then:
  - If `$XDG_CONFIG_HOME` is a non-empty string, the default path is `$XDG_CONFIG_HOME/ghtui/config.yml`.
  - If `$XDG_CONFIG_HOME` isn't set, then:
    - On Linux and macOS systems, the default path is `$HOME/.config/ghtui/config.yml`.
    - On Windows systems, the default path is `%USERPROFILE%\.config\ghtui\config.yml`.

</details>
